# pop-microarray-affymetrix
Este POP descreve o fluxo padronizado para processamento e análise de dados de expressão gênica provenientes de microarrays Affymetrix, incluindo controle de qualidade, normalização, análise de expressão diferencial e visualização dos resultados, visando garantir a reprodutibilidade e a rastreabilidade das análises bioinformáticas.
